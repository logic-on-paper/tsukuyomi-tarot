画像は縦長（比率 7:12 前後、例: 700×1200 ピクセル）にしてください。
比率が違う場合は、中央を残して上下または左右が切り取られます。

置いたあと、index.html の中の
  const CARD_IMAGES = false;
を
  const CARD_IMAGES = true;
に変えると、内蔵の図柄の代わりに画像が表示されます。
