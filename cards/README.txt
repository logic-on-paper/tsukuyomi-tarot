自作のカード画像を使う場合は、このフォルダに次の名前で置いてください。

  00.png  愚者          11.png  正義
  01.png  魔術師        12.png  吊るされた男
  02.png  女教皇        13.png  死神
  03.png  女帝          14.png  節制
  04.png  皇帝          15.png  悪魔
  05.png  教皇          16.png  塔
  06.png  恋人          17.png  星
  07.png  戦車          18.png  月
  08.png  力            19.png  太陽
  09.png  隠者          20.png  審判
  10.png  運命の輪      21.png  世界

画像は縦長（比率 7:12 前後、例: 700×1200 ピクセル）にしてください。
比率が違う場合は、中央を残して上下または左右が切り取られます。

置いたあと、index.html の中の
  const CARD_IMAGES = false;
を
  const CARD_IMAGES = true;
に変えると、内蔵の図柄の代わりに画像が表示されます。
